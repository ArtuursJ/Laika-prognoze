# Laika-prognoze
## Šī lietotne palīdz lietotājiem ātri un vienkārši saprast, ko vilkt, balstoties uz aktuālajiem laikapstākļiem. Tā apkopo laika prognozes datus un piedāvā piemērotu apģērba ieteikumus dažādām situācijām (auksts, lietains, karsts u.c.). Lietotne ir paredzēta ikdienas lietošanai cilvēkiem, kuri vēlas ietaupīt laiku un izvairīties no nepiemērota apģērba izvēles.
## Izmantotās tehnoloģijas: SQL, HTML PYTHON, APi
